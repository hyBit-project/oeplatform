hyBit Table Creation Wizard


Hier kannst du basierend auf einer CSV-Datei die Datenbankstruktur anlegen lassen.
Das Tool rät dabei automatisch anhand des ersten Datensatzes die möglichen Dateiformate.
Danach geht's dann im "normalen" Wizard weiter, wo die CSV-Datei (leider noch) erneut hochgeladen werden muss.

Es wird automatisch zusätzlich eine ID-Spalte mit primary key angelegt (OEP Konvention).
Sofern der Datensatz ebenfalls eine entsprechende Spalte hat, wird die Spalte automatisch zugeordnet. Ansonsten bleibt die ID-Spalte erstmal ohne Daten.

Alternativ gibt es hier den Standard-OEP-Editor.
